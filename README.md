

Aplikasi ini dibuat menggunakan Android Studio dengan bahasa pemrograman Kotlin dan Jetpack Compose. Beberapa input control yang diimplementasikan antara lain:

Input Nomor HP menggunakan OutlinedTextField untuk menerima input berupa nomor telepon.

Date Picker dengan DatePickerDialog, yang menampilkan pemilih tanggal dan hasilnya ditampilkan dalam bentuk Toast.

Toast digunakan untuk menampilkan pesan singkat kepada pengguna.

Alert Dialog digunakan untuk menampilkan pesan peringatan dengan pilihan OK dan Batal.

Semua komponen ini disusun menggunakan pendekatan deklaratif Jetpack Compose dan dikelola dengan state yang reaktif menggunakan remember dan mutableStateOf.
